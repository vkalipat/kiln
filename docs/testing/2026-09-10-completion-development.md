## Fixed task-level comparison

Two Python-standard-library CLI contracts and independent external behavioral checks were fixed before generation: Unicode slug normalization and exact CSV category totals. The CSV task includes decimal precision, input rejection, ordering, and no-partial-output requirements. Both require a README and discoverable, passing model-authored tests. Those tests are scored separately from the external checks.

The simple arm uses Fable 5.1 at xhigh with ordinary read/write/edit/bash tools. Full Kiln uses its native adaptive direct workflow, Fable production seats and independent Opus 5 critique/audit seats at xhigh. General output allowance is 16,384 tokens; strict critique/audit allowance is 32,768. Fallback and transport retries are disabled. Each arm has a 25-minute wall limit and conservative per-request accounting; simple/full arm limits are $3/$10.

Controller-side checks and prior-arm artifacts are not supplied to workers. Worker homes are separate opaque temporary directories, but tools are not OS-sandboxed. Therefore these are independent external checks, not security-isolated hidden benchmarks. Tool-argument inspection and independent source review are required before accepting a result. A reused baseline is explicitly labeled a diagnostic control, not a newly independent paired trial.

Delivery, artifact correctness, and reflection outcome are distinct. Kiln intentionally preserves a successful build's outcome if optional reflection fails; a successful native exit alone does not establish that every requested phase succeeded.

## Corrections under qualification

- Validated canonical frame/discovery writes finish their phase without a redundant model narration call, while pending user steering remains deliverable.
- Repairable formation feedback gets bounded, durable revision and independent re-review. Exhaustion is a resource failure, not proof that a concept is infeasible.
- Small direct tasks can use one verifiable feature rather than inventing unrelated feature slots.
- Greenfield output-location wording and `unittest discover` no longer misclassify the complete task prompts as existing-artifact work or idea discovery.
- Dependency declarations reject prose and command expressions before freezing; explicit executable paths and environment-variable names remain supported. Version predicates belong in executable initialization checks.
- Direct critics receive the original request, with the generated brief subordinate to it. Optional design choices are distinguished from user requirements.
- Critics receive bounded, harness-recorded formation execution evidence, with omission counts, exit/signal/timeout/cancellation facts, and explicit truncation. Legacy completeness remains unknown; tool-wrapper success is not process success.
- Discovery synthesis receives existing, fingerprint-valid findings directly, including failed-question gaps and overflow paths. Researchers receive a cooperative retrieval cutoff before the hard deadline, leaving time to summarize actual evidence. All-failed retrieval still stops honestly.
- The evaluator now distinguishes signal/time-limit termination from a legitimate high nonzero exit code, audits all prior worker homes, uses native project reservation, and separates delivery from reflection outcomes.
- Large acceptance checks retain their exact frozen JSON in the builder's current context, with a compact artifact/id/hash reference in the bounded pin. Each attempt verifies the authoritative features and lock before dispatch. Neither the check nor the audit is weakened to fit a display allocation.
- Critic decisions require coherent structure: acceptance has no blocking findings; revision has at least one. Contradictions retry within the critic's existing bound instead of silently passing or spending a producer-revision cycle.
- Relative executable dependencies resolve in the actual execution directory. Formation rejects literal NUL command bytes and lexical parent traversal in file checks consistently with downstream verification.
- Shell tools lazily allocate unique, retained run-local temporary directories and override common temporary-directory variables. Live tool guidance prohibits pre-cleaning guessed paths and deleting unknown contents. This is not an OS sandbox.
- Explicit resume can re-enter failed build verification/transient errors through the normal native guards, without resetting cost, active time, attempts, or locked contracts. Integrity, policy, refusal, completed, and failed-resource cases retain their prior refusal rules.
- Full validated audit payloads retain provenance and hashes; presentation clipping cannot convert a disagreement into agreement. Current and future feature scopes are supplied to the auditor. Unavailable reviews consume the existing bounded attempt allowance and cannot pass a feature. Legacy records are not silently authenticated as complete.
- The ideation evaluator queues exact-wire reservations under temporary financial contention rather than cancelling already-dispatched parallel work. Queued requests cost zero and cannot dispatch after cancellation; genuinely uncertain dispatched usage remains reserved.

The post-sizing software suite passed **1,729 tests, zero failures** (10,839 assertions, 191 files), with TypeScript and diff checks passing. Independent review found no remaining blockers in the portfolio-sizing changes. Live qualification of the new source is in progress; these tests do not establish live task success.
