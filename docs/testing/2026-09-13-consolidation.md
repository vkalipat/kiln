# Context and orchestration consolidation — 2026-09-13

## Intent

Consolidate the existing harness around reliable agent handoffs and task-appropriate use of frontier models. This is not an RLT model implementation, a new memory service, or an additional generic reflection loop.

The [historical formation/build record](../design/formation-build.md) described a mandatory second critique. This release intentionally revisits that ordering: a mechanically valid, unchanged plan with one coherent independent approval does not need a no-feedback rewrite and another review. Real revision requests retain bounded repair and independent re-review. Historical design documents remain unmodified.

## Changes being qualified

1. Newly planned adaptive direct tasks requiring no research use deterministic intake instead of a paid framing call. The original seed remains authoritative and exact; provisional framing metadata does not claim research or invent user facts. Historical/manual/evaluation plans retain their prior framing behavior.
2. A clean independent formation approval can freeze the exact reviewed artifacts immediately. Stale approval, changed bytes and interrupted revisions cannot authenticate different artifacts. Existing approval receipts, locks and recovery stages are reused.
3. The direct builder receives the complete original request in its stable context, while its current feature and frozen acceptance contract remain its assigned scope.
4. The probe selector receives whole canonical dossiers with identity, source path, size and hash. A bounded packet defers oversized artifacts explicitly instead of silently clipping them. Already-probed and rejected work is excluded. Existing read tools and conservative budget projections remain available for overflow.
5. Completed discovery can use unrequested-phase wall headroom for local synthesis only. Initial research windows remain unchanged; frozen and currently requested phases are unioned before calculating headroom. Ideation shares that cumulative wall accounting, and total time, dollar and turn limits never reset on resume. The CLI rechecks authoritative status and the resume route under its command lock before waking work.
6. Scout source URLs are collected from that scout's successful tools, not a shared journal time window. The existing collision review explicitly assesses search coverage; insufficient, unavailable or unverified decisions remain unknown. Successful direct primary-source fetches can reach review despite failed search backends. Gap reasons survive in evidence and rendered context; the renderer version is bumped from 1 to 2 to reflect changed bytes and calibration identity. No new model call or search service is added.

Provider identities, model eligibility, reasoning controls, independent audits, acceptance locks, cancellation and spending limits are not relaxed to obtain faster results. Observed mock-call reductions are not presented as measured dollar savings.
