# Kiln runtime routing and frontier maintenance acceptance

This follow-up extends the [earlier local v1 pass](2026-09-28-v1.md). It adds active Jev routing, Kiln authentication branding, a larger terminal animation, catalog drift detection, maintained dependency updates, and a user manual. The earlier receipt remains a record of its own source state.

## Delivered behavior

- New operator runs with a configured TypeSafe key classify submitted work and automatic handoffs with pinned Jev. Explicit steps bypass classification. Compatibility and credential admission remain Kiln's responsibility; independent review remains a separate worker.
- Classification uses the shared budget, bounded calls and observed tokens, cancellation, confidence fallback, and an in-memory cache. Attempts are persisted before transport so interrupted requests cannot reset the allowance. Meter shutdown is awaited before a run lock is released.
- Terminal authentication and the local browser receipt are branded Kiln. A tracked Bun patch provides the optional callback renderer without changing client identity, PKCE, callback validation, or token exchange. The receipt does not claim exchange is complete.
- The welcome screen has a large amber-white wordmark and rotating wireframe core/orbits at a shared 100 ms cadence. Compact layouts and static `NO_ANIMATION` behavior remain available.
- Catalog status/check commands report installed metadata and upstream differences. New operator runs fingerprint admitted model definitions and selected role references; resume rejects drift before dispatch. Legacy runs establish a baseline when first resumed.
- A six-hour/manual GitHub workflow checks the official npm registry, prepares exact common native-package updates, preserves the reviewed OAuth patch, and runs compatibility gates before a draft PR. Publication uses a separate job without executing upgraded dependencies. No auto-merge is configured.
- The [user manual](../user-manual.md), [architecture guide](../architecture-and-integrations.md), and [Word manual](../Kiln-User-Manual.docx) explain the actual integration boundaries. All eight Word pages were rendered and visually checked; command blocks and link targets were verified.
