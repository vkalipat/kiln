# Native 18.4.2 compatibility receipt

Status: final frozen local validation passed. Remote CI and the automated updater run remain pending; this is not yet a remote release-pass receipt.

## Dependency and compatibility changes

The six official `@oh-my-pi` packages (`pi-agent-core`, `pi-ai`, `pi-catalog`, `pi-coding-agent`, `pi-tui`, and `pi-utils`) are pinned to exactly `18.4.2`. Exact-version resolution fails closed rather than silently substituting another model or package version.

- Adapted authentication to the new namespaced key API while retaining session ownership and cancellation checks. Host credential resolution requires an admitted provider and an active owned session; metadata discovery does not resolve bearer credentials. Cancellation is checked around asynchronous resolution.
- Migrated mock imports across 62 test files to the upstream runtime export location.
- Reviewed the OAuth branding patch for the new package. Its SHA-256 is `7e1df3ff73a91df1482a5f7af68724b926ef33a24b2ef168e9f1eb1288bbd036`. The installed-patch checker validates the complete expected post-image context of every hunk, exact target files, and unique inserted text; a matching patch-file hash alone is insufficient.
- Updated native orchestration guidance to use `task`, write to `agent://<id>` for agent messaging, and use `wait` when blocked without independent work.
- Audited catalog resolution: all 10 configured roles resolve across three providers. Role fallback tests were updated to the current catalog; an available fallback is not assumed to have the price of the retired model.
