# Kiln plugin

Use Kiln from Codex or Claude Code. Installation, helper commands, and state handling are in the [Kiln reference](https://github.com/vkalipat/kiln/blob/main/docs/README.md#assistant-plugins).

The [run skill](skills/run/SKILL.md) contains the assistant's operating instructions. The plugin needs Python 3.10+, Bun, and an installed `kiln` command. Installation does not start work or call a model.
